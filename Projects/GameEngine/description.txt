Unnamed Game Engine
---
A personal improvment project, I am working on creating a game engine after being inspired by my 3rd year module which required the same thing to be done.
<br>
While the project is still in it's infancy, I have been using it to learn about many different programming paradigms and patterns. With my end goal of creating a game in the engine, I have also been focusing on creating robust, extendable and API agnostic systems that allow for easy interface with multiple different APIs. The engine currently supports OpenGL and I am aiming to add both Vulkan and DirectX 12 as supported graphics APIs.
<br>
As this is a game engine with a game in mind, I am planning on adding low level aerodynamic simulation into the engine. This has already been experimented with using Unreal Engine (see project: https://benjpurdy.github.io/Projects/FlightSimulation/FlightSimulation.html) 
<br>
Code for the project can be found here: https://github.com/itsBowl/UnnamedGameEngine
